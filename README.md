# MandiBahi (मंडी बही-खाता व मण हिसाब)

**MandiBahi** is an intuitive, fast, and comprehensive digital trade ledger and daily register designed specifically for agricultural markets, grain & cotton mandis, commission agents (आढ़ती / दलाल), and traders.

---

## 🌟 मुख्य विशेषताएं (Key Features)

- **तौल व मण हिसाब (Weight to Maund / Man Conversion)**:
  - 1 मण = 20 किलो (20 kg - Gujarat, Malwa, cotton standard) एवं 1 मण = 40 किलो (40 kg - North India standard) के बीच तुरंत स्विच।
  - कुल वजन (Gross Kg) और बारदाना कटौती (Tare Kg) से तुरंत शुद्ध वजन एवं मण (Man) गणना।
  - भाव प्रति मण (₹/Man) और भाव प्रति क्विंटल (₹/Quintal) का रीयल-टाइम तालमेल।

- **मंडी खर्चे व शुद्ध देय राशि (Mandi Expenses & Net Payable)**:
  - आढ़त/कमीशन (%), हमाली (₹ प्रति बोरी), कांटा तुलाई और पेशगी एडवांस घटाकर किसान को अंतिम देय राशि (अक्षरे रुपयों में)।

- **प्रिंट एवं व्हाट्सएप बिक्री पर्ची (Printable & WhatsApp Bill Slip)**:
  - थर्मल या A4 प्रिंटर के लिए आधिकारिक मंडी पर्ची फॉर्मेट।
  - 1-क्लिक में किसान को व्हाट्सएप पर पूरा बिल विवरण भेजने की सुविधा।

- **दैनिक व्यापार बही (Daily Trade Register)**:
  - आज, कल, या महीने भर के सभी सौदों का हाई-डेंसिटी रिकॉर्ड।
  - फसलवार और पार्टीवार फ़िल्टर एवं 1-क्लिक CSV एक्सपोर्ट।

- **खाताबही (Party Accounts Ledger)**:
  - किसान एवं खरीदार का खाता, कुल व्यापार, चुकाया गया भुगतान और शेष बाकी (Balance Due)।
  - नकद, UPI या बैंक भुगतान दर्ज करने की सुविधा।

- **लाइव मण कैलकुलेटर (Spot Calculator)**:
  - मंडी यार्ड में खड़े-खड़े तुरंत किलो से मण और भाव निकालने का त्वरित साधन।

## 🚀 Run Locally

### Prerequisites
- Node.js (v18+)
- npm or bun

### Installation
```bash
# Clone the repository
git clone <your-repository-url>
cd mandibahi

# Install dependencies
npm install

# Start development server
npm run dev
```

App will run at `http://localhost:3000`.

### Build for Production
```bash
npm run build
```
